# Talk2Deal
Talk2Deal is an intelligent AI-powered negotiation system designed to assist users in making better decisions during bargaining scenarios. The system analyzes user inputs, evaluates negotiation strategies, and provides optimized responses to improve outcomes in real-time.

In a world where effective negotiation is critical—whether in business deals, salary discussions, or everyday transactions—Talk2Deal acts as a smart assistant that enhances decision-making through AI-driven insights.

# Objectives
To develop an AI-based negotiation support system

To analyze user behavior and generate optimal negotiation strategies

To simulate real-world negotiation scenarios using intelligent algorithms

To improve decision-making through data-driven insights

# System Architecture

The system follows a modular architecture consisting of:

User Interface Layer – Handles interaction with users

Processing Layer – Processes input and applies logic

AI/ML Model Layer – Generates negotiation strategies

Database Layer – Stores negotiation data and patterns

# ⚡ How to Access and Run This Project

Follow these steps to run the Talk2Deal AI system locally:

📥 Step 1: Clone the Repository

📂 Step 2: Navigate to the Project Folder

⚙️ Step 3: Install Dependencies

Make sure Python 3.x is installed, then run: pip install -r requirements.txt

▶️ Step 4: Run the Main Application (User Interface) -> streamlit run streamlit_app.py

🔐 Step 5: (Optional) Run Admin Panel -> streamlit run streamlit_admin.py

🌐 Step 6: Open in Browser

After running, Streamlit will automatically open in your browser. If not, go to: http://localhost:8501
